# ATYA

Chat-first personal memory: capture anything through Telegram, have it sorted
into typed records, and ask questions answered from your own data.

Status: v1 code (`assistant_bot/`, Telegram -> Notion) imported as the starting
point for v2 (Postgres, multi-user, export/delete, web view). See the v2 spec
for the plan; nothing in v2 has been built yet.
